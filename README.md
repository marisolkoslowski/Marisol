Fork "cat" to create a new MOOSE-based application.

For more information see: [https://mooseframework.org/getting_started/new_users.html#create-an-app](https://mooseframework.org/getting_started/new_users.html#create-an-app)
# cat

This app couples thermal transport, mechanics, thermal kinetics and plasticity using a finite strain framework
The user defines two equations of state for both reactants and products, and can evolve the model using different conditions
